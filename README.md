# 📈 Simulador de Investimentos em Fundos Imobiliários - Excel

Este projeto foi desenvolvido como parte de um laboratório prático do Bootcamp do DIO Santander - Excel com IA, com o objetivo de aplicar conceitos de Excel na criação de uma ferramenta funcional de **simulação de investimentos em fundos imobiliários (FIIs)**.

## 🎯 Objetivo

A planilha permite que investidores simulem diferentes cenários de investimentos em FIIs, respondendo às principais perguntas como:

- 📊 **Quanto investir?**
- ⏳ **Por quanto tempo?**
- 💰 **Qual a taxa de rendimento mensal?**
- 🏦 **Qual será meu patrimônio acumulado?**
- 📅 **Quais os dividendos mensais esperados?**

## 🚀 Funcionalidades

- Cálculo automático de:
  - ✅ Valor total investido
  - ✅ Patrimônio acumulado ao longo do tempo
  - ✅ Dividendos mensais estimados
- Interface intuitiva e fácil de preencher
- Simulação de cenários variando:
  - Valor do aporte inicial
  - Aportes mensais
  - Período de investimento
  - Taxa de rendimento mensal

## 🛠️ Ferramentas utilizadas

- Microsoft Excel
  - Fórmulas
  - Funções financeiras
  - Layout amigável e organizado

## 📝 Como utilizar

1. Faça o download do arquivo [`Projeto invest 2.xlsx`](./Projeto%20invest%202.xlsx).
2. Abra no Excel (recomendado versão 2016 ou superior).
3. Preencha os campos indicados com:
   - Valor do aporte inicial
   - Aportes mensais
   - Período de investimento
   - Taxa de rendimento mensal
4. Veja os resultados atualizarem automaticamente, com visão clara do patrimônio e dos dividendos futuros.
